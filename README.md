# Kindly Hub — React + TypeScript (TSX) + Material UI

## Pages
- Home dashboard
- Tickets
- ITSM
- Issues
- Boards
- Inbox
- Planner
- Contacts
- Templates
- Automation
- Analytics
- Settings

Each React component/page is a separate `.tsx` file. Theme and entry configuration use TypeScript (`theme.ts`, `main.tsx`, `App.tsx`, `vite.config.ts`).

## Run locally
1. Install Node.js (LTS version recommended).
2. Extract this ZIP.
3. Open the extracted `Kindly_Hub_MUI_TSX` folder in VS Code.
4. In the terminal, run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually http://localhost:5173).

Optional commands:

```bash
npm run build       # Create production build
npm run typecheck   # Run TypeScript type checking
```

## Notes
This is a multi-page frontend starter built with React, TypeScript, Material UI, React Router, and Recharts. Sample records and metrics are demonstration data. It does not connect to the original Node.js backend or database yet.
